# Architecture

## Product focus

This project is designed as a world-clock-like solar and UV exposure tracker, not a generic weather app.

## Layers

```
App/Daystar/           SwiftUI app target (Daystar.xcodeproj)
Sources/daystar-ios/   offline domain engine, no UI dependency
```

The app target consumes the engine as a local Swift package product. Nothing in `Core/`
imports SwiftUI, so the engine stays testable on macOS via `swift test` and reusable from a
future widget or watch target.

## App layer

```
App/Daystar/
  DaystarApp.swift        entry point
  AppModel.swift          @Observable state: selected city, skin type, scrubbed time
  Views/
    RootView.swift        hero card, exposure card, solar events
    DayCurveView.swift    Swift Charts day curve with drag-to-inspect
    CityPickerView.swift  offline city search and comparison
    SkinTypeView.swift    Fitzpatrick selector
  Support/                UV bands, formatting
  Assets.xcassets/        app icon (generated by Scripts/make-appicon.swift), accent color
```

`SolarReading` assembles position, irradiance, UV and burn estimate for one instant in a
single pass, so every part of the screen describes the same moment — including while the
user is scrubbing the chart.

## Data flow

Astronomy → Irradiance → UV model → Burn-time estimate

1. `SolarCalculator` computes solar geometry from place/time.
2. `IrradianceCalculator` computes clear-sky solar irradiance (W/m²).
3. `UVModel` estimates erythemally weighted irradiance and modeled UV potential.
4. `BurnTimeEstimator` maps Fitzpatrick threshold range to an estimated unprotected burn-time range.

## Offline vs future live data

- Current values are modeled clear-sky estimates.
- `UVConditionsProvider` defines an optional integration point for future observed/forecast UV and atmospheric data.
- Core app utility must remain available without any provider implementation.

## Units

Strongly typed domain wrappers are used for:

- `PowerPerArea` (W/m²)
- `EnergyPerArea` (J/m², Wh/m² conversion)

This avoids raw-`Double` ambiguity in exposure calculations.
